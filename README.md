# Borrow-Back

Borrow-Back is a peer-to-peer item lending and borrowing application. It allows community members to list personal items for rent, set daily rental prices and security deposits, and track borrowings, returns, and overdue fees.

## Setup

### Backend
1. cd server
2. npm install
3. Configure .env with PORT, MONGO_URI, and JWT_SECRET
4. npm start

### Web Frontend
1. cd client
2. npm install
3. npm run dev

### Mobile App
1. cd mobile
2. npm install
3. npx expo start
